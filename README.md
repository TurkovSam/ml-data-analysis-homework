# Домашнее задание по курсу "Программные инструменты анализа данных"

**Студент:** [Турков Семён Михайлович]  
**Направление:** Информационная Безопасность (ИБ)  
**Тема:** Разведочный анализ данных (EDA) в задаче обнаружения вредоносных URL-адресов.

## 1. Постановка задачи и выбор данных
* **Бизнес-постановка:** Реализация модуля автоматического анализа веб-ссылок (URL) для корпоративной системы обнаружения угроз (IDS/SIEM), позволяющего блокировать фишинговые и вредоносные сайты в реальном времени.
* **ML-постановка:** Задача бинарной классификации. Объект — текстовая строка URL. Целевая переменная \(y \in \{0, 1\}\), где `0` — легитимный URL (benign), `1` — вредоносный/фишинговый URL (malicious).
* **Набор данных:** Открытый датасет "Malicious URLs Dataset" (содержит >650,000 записей). Для анализа взята случайная репрезентативная выборка в 20,000 строк.

## 2. Выбор и обоснование метрики
* **Метрики:** Комплексная метрика **F1-score**, а также детальный контроль **Recall (полноты)** для вредоносного класса.
* **Обоснование:** В сфере ИБ критически важно минимизировать пропуски атак (ошибки False Negative), поэтому метрика Recall является приоритетной. Тем не менее, слишком частые ложные срабатывания (False Positive) заблокируют легитимную работу пользователей, поэтому максимизация F1-score обеспечит необходимый баланс точности и полноты модели.

## 3. Как запустить проект
Полный разведочный анализ данных (EDA) с расчетом базовых статистик, генерацией признаков и визуализацией на `matplotlib/seaborn` представлен в файле ноутбука в данном репозитории.
